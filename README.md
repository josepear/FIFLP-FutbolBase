# FIFLP Fútbol Base

Aplicación de seguimiento de rendimiento para fútbol base (FIFLP — Federación Interinsular de Fútbol de Las Palmas), extrapolada de WaterMetro.

## Categorías de fútbol base (RFEF/FIFLP)
Prebenjamín (Sub-8/9, F-8) · Benjamín (Sub-10/11, F-8) · Alevín (Sub-12/13, F-8) · Infantil (Sub-14/15, F-11) · Cadete (Sub-16/17, F-11) · Juvenil (Sub-18/19, F-11) · Sénior · Veteranos.

## Stack previsto
React 19 + TypeScript + Vite + Tailwind + Supabase + Dexie + Recharts.
